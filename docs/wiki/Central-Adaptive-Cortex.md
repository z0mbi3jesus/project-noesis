# Central Adaptive Cortex (CAC)

The CAC is the intended coordinating and integrating component of NOESIS. It retains
final decision-making authority. Specialized lobes contribute processing results
for its evaluation.

## What is implemented

Current symbol benchmarks use explicit developer-supplied coordination rules:

```text
Input → CAC receives input
      → Language lobe identifies the symbol
      → CAC receives the identification
      → Cognitive processing lobe compares against earlier encounters
      → CAC checks comparison evidence
      → Retention and observable result
```

The CAC owns session-local encounter history. Comparison is exact and case-sensitive.
The language lobe validates the configured input domain and classifies accepted
characters. Neither lobe assigns semantic meanings or independently commits history.
Processing is synchronous and begins with submitted input.

## Intended direction, not current capability

The broader concept includes ongoing integration, uncertainty and contradiction
handling, reconsideration when context changes, and preparation of supporting
processing capacity as overload approaches. Relevant mechanisms and authority
boundaries require further research and approval.

Lobes are intended to remain receptive to delivered information rather than scan
continuously for work. Multiple components may eventually work concurrently.
The current benchmark does not demonstrate that concurrency or adaptive scaling.

The CAC is the proposed location of system identity and agency. This architectural
intention does not establish consciousness, subjective experience, or personhood.
"Adaptive" in the name is not evidence that adaptive learning is implemented.

Processing records are traceable experimental observations. Their current format
is not a permanent cognitive flag language.
