# Welcome to Project NOESIS

NOESIS is an experimental investigation into non-neural computational cognition.
This wiki introduces the research, its current evidence, and ways to participate.

**Current stage:** Research Cradle v0.4.1; Benchmark 002 validation and review.
**Tester downloads:** on hold. **Licensing:** restricted research-and-development
participation; no general open-source implementation license.

Current results concern explicit symbol identification, classification, comparison,
and session-local retention. They do not establish semantic understanding, generalized
learning, autonomous reasoning, consciousness, or independent cognition.

The public repository contains documentation, not the implementation. The wiki does
not grant access to unpublished materials or authorize an application download.

To suggest a correction, open a documentation issue or pull request in the
[public repository](https://github.com/z0mbi3jesus/project-noesis).
