# Glossary

| Term | Meaning in the current project |
| --- | --- |
| CAC | Central Adaptive Cortex; intended central coordination and integration authority |
| Lobe | Specialized component providing processing contributions to the CAC |
| Cradle | Replaceable research control and observation environment |
| Symbol | One character in the selected benchmark's allowed ASCII set |
| Submission | An input sent for processing; it may be accepted, rejected, blocked, failed, or incomplete |
| Encounter | An accepted submission retained in the current session; not a keyboard press |
| Encounter number | Position of an accepted input in that session's ordered history |
| Previous encounters | All earlier accepted encounters containing the exact same symbol |
| Occurrence at encounter | Number of earlier exact matches plus one, including this encounter |
| Submission ID | Diagnostic identity distinguishing attempts, including rejected attempts |
| Session | One initialized experimental history and lifecycle; separate from other benchmark sessions |
| Classification | Supplied category such as Uppercase alphabetic, Lowercase alphabetic, or Numeric digit |
| Processing phase | A recorded stage of actual processing, not an invented reasoning explanation |
| Flags | Informal term for component-owned processing records; no permanent cognitive flag language is selected |
| Functional correctness | Whether explicit checks are satisfied for a defined experiment |
| Session execution ended | The initialized session has been stopped; not an assessment of success |
| Formal benchmark assessment | A separate research acceptance process; not implied by Stop or a successful input sequence |
| Diagnostic journal | Persisted observational evidence, distinct from cognitive memory |
| Learning | A research target requiring evidence beyond programmed retention or comparison |

The same terms should be used consistently in experimental protocols, reports,
interface descriptions, and discussions. Propose clarifications through the
[public repository](https://github.com/z0mbi3jesus/project-noesis).
