# Project overview

NOESIS explores whether useful cognitive mechanisms can be developed without
artificial neural networks. It uses small experiments to investigate distinct
capabilities rather than claiming an entire architecture works from one result.

## Direction

The intended architecture has a Central Adaptive Cortex (CAC) and specialized
processing lobes. Functional specialization is an organizational analogy; the
project is not an anatomical brain simulation. Neural networks and pretrained
language models are not used in the current implementation.

Longer-term questions include knowledge integration, uncertainty, revision,
internally initiated investigation, and bounded adaptive processing capacity.
These remain research questions, not implemented features.

## Development method

Design → approved implementation → benchmark → analysis → validation → review.

The project lead makes final scope and architectural decisions. Research/design
and implementation collaborators support that process. Community proposals do not
automatically authorize new cognitive mechanisms or benchmarks.

## Current position

Research Cradle v0.4.1 supports two symbol benchmarks. Benchmark 001 establishes
an uppercase-only baseline; Benchmark 002 expands the domain to 62 ASCII symbols
and investigates deeper encounter histories. Benchmark 002 remains under review.
Benchmark 003 has not begun.

The project distinguishes information processing, retention, recognition, learning,
reasoning, understanding, and autonomous behavior. Evidence for one is not evidence
for all of them. Failed hypotheses and unexpected results are useful observations.
